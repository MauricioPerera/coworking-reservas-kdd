# Objetivo activo

Crear y validar un gestor local de reservas de salas que ejercite contratos
sellados, pruebas funcionales, cinco mutaciones, siete casos de Chromium,
KDD Board, integridad de controles y CI auténtico en Ubuntu y Windows.

La aceptación está en specs/CONTRACT-01-reservas.md. Primero se registran
oráculos y stubs; después se implementan solo rutas de producción. La siguiente
etapa requiere una aprobación humana del candidato concreto, seguida de gate,
CI y cierre documental respaldado por sus artefactos. No está completo hasta
que se verifican todos esos resultados. El proyecto original permanece intacto.
